## MVP 1.0 — 2026-08-07

### Реализовано

- **Ввод данных**
  - Ручной ввод сетки измерений: пресеты 5×5, 7×7, 10×10 и произвольный размер до 50×50.
  - Импорт CSV-файла (матрица значений; разделители `;` и `,`; десятичная запятая поддерживается).
  - Экспорт текущей таблицы в CSV.
  - Валидация сетки: полнота заполнения, дубли координат, конечность значений, диапазон значений (по умолчанию ±1000 мТл).

- **Анализ**
  - Статистика: min, max, mean, median, std; коэффициент неоднородности (std/mean×100%).
  - Координаты точек максимума и минимума; центр концентрации поля (взвешенный центр масс).
  - Интерполяция поля на регулярную сетку методом RBFInterpolator (thin-plate spline), разрешение 100×100.
  - Поиск связных зон («горячих» и «холодных») по порогу mean ± k·std.
  - Карта градиента поля (величина изменения между соседними точками).

- **Визуализация**
  - Тепловая карта поля и градиента с наложенными точками измерений.
  - Автоматическая и фиксированная цветовая шкала (задаётся вручную).

- **Отчёт**
  - Предпросмотр отчёта: карта + статистика + зоны + сырые данные, метод интерполяции и калибровочное смещение фиксируются в тексте отчёта.
  - Комментарий к эксперименту.
  - Экспорт отчёта в PNG и PDF.

- **Хранение проекта**
  - Сохранение проекта в один JSON-файл (меню «Файл» → «Сохранить проект…», Ctrl+S).
  - Открытие проекта (Ctrl+O) с восстановлением сетки, комментария и пересчётом анализа.
  - Схема файла версионируется полем `schema_version` (текущая: 1).

- **Сборка и CI**
  - PyInstaller-спецификация (`TILDA.spec`), сборка в один исполняемый файл.
  - Скрипт сборки для Windows (`build_windows.bat`).
  - GitHub Actions workflow: автоматическая сборка Windows exe (по тегу `v*` или вручную).

- **Качество**
  - 56 тестов (unittest) по всем модулям: модели, ввод, CSV, интерполяция, статистика, зоны, тепловые карты, отчёт, JSON-хранилище.

### Известные ограничения

- В проекте хранится один активный эксперимент за раз (список экспериментов в формате проекта предусмотрен, но GUI работает с текущим экспериментом).
- Сравнение экспериментов и профили сечений — вне MVP (заделы в `analysis/comparison.py` и `visualization/profile.py`).
- Значение `z` (объёмные измерения) сохраняется в файле проекта, но не используется в UI и анализе.
- Единицы измерения и калибровочное смещение фиксированы (mТл, 0.0) — поля есть в модели и отчёте, но не редактируются в GUI.
- Проверка диапазона значений применяется при вводе/импорте; при загрузке проекта значения пересчитываются и валидируются повторно.
- Сборка `.exe` выполняется на Windows (локально или через GitHub Actions); macOS-версия собирается без артефактов Windows.
